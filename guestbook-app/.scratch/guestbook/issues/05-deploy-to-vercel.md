# 05: Vercel 배포와 최종 점검

**What to build:** 누구나 공개 URL로 방명록에 접속해 글을 쓰고, 보고, 자기 글을 비밀번호로 수정·삭제할 수 있다. 배포된 사이트가 스펙의 모든 조건을 만족하는지 직접 확인한다. Vercel 계정 연결과 환경변수 등록 등 사람이 해야 하는 단계가 포함된다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 03 (비밀번호로 메시지 수정), 04 (비밀번호로 글 삭제)
