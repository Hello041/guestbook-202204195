# 04: 비밀번호로 글 삭제

**What to build:** 글쓴이가 자기 글의 [삭제]를 누르면 그 글 아래에 비밀번호 입력 폼이 열린다. 비밀번호가 맞으면 글이 목록에서 사라진다. 비밀번호가 틀리면 삭제가 거부되고 폼 안에 "비밀번호가 일치하지 않습니다."가 표시된다. 스펙: `.scratch/guestbook/spec.md` (사용자 스토리 35~41).

**Blocked by:** 02 (글 작성과 최신순 목록). 03과 병행 가능.

**Status:** done

- [x] 각 글에 [삭제] 버튼이 있고, 누르면 그 글 아래에 인라인 삭제 폼이 열린다 (비밀번호 입력칸 가림, 삭제/취소)
- [x] [취소]를 누르면 글이 남아 있고 폼이 닫힌다
- [x] 비밀번호 비교는 서버의 방명록 모듈에서 타이밍 안전 비교로 이루어진다
- [x] 비밀번호 불일치 시 폼 안에 빨간 글씨로 "비밀번호가 일치하지 않습니다."가 표시되고 글은 삭제되지 않는다
- [x] 없는 글이면 "이미 삭제되었거나 존재하지 않는 글입니다."가 안내된다
- [x] 성공 시 그 글이 목록에서 바로 사라진다 (별도 팝업 없음)
- [x] 제출 중 버튼이 비활성화된다
- [x] 모듈 테스트(메모리 저장소): 맞는 비밀번호로 삭제 시 목록에서 사라짐, 틀린 비밀번호 시 불일치 반환·글 유지, 같은 이름의 다른 글 비밀번호로 삭제 불가, 없는 id는 "없는 글"
- [x] 로컬(`next dev`)에서 삭제 성공·불일치 흐름을 수동 확인했다
- [x] `npm test`, `npm run build`, `npm run lint`가 통과한다
